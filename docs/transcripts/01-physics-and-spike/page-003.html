# Skill mechanics

The skill-specific branch of [`writing-for-agents`](SKILL.md): what changes when the document is a skill (frontmatter, the invocation choice, and router skills). Everything else about writing it is the universal reference in `SKILL.md`.

## Invocation

Two choices, trading the two loads:

- A **model-invoked** skill keeps a `description`, so the agent can fire it autonomously, and other skills can reach it. You can still type its name: model-invocation always _includes_ user reach; a description only ever adds agent discovery, never removes the human's. The description is the skill's top-level context pointer, forced to stay loaded at all times: permanent context load in exchange for discoverability. A model-invoked skill whose content is all reference is also one home for shared reference: another skill can invoke it, so reference needed by several skills lives in one place. Mechanics: omit `disable-model-invocation`, and write a model-facing description carrying the trigger branches (the pointer-writing rules in `SKILL.md` apply in full).
- A **user-invoked** skill strips the description from the agent's reach: only the human typing its name can invoke it, and no other skill can. Zero context load, but it spends cognitive load: you are the index that must remember it exists. Mechanics: set `disable-model-invocation: true`; the `description` becomes human-facing: a one-line summary, trigger lists stripped.

Pick model-invocation only when the agent must reach the skill on its own, or another skill must. If it only ever fires by hand, make it user-invoked and pay no context load.

Shared reference that two user-invoked skills both need can live in neither: with no descriptions, neither can fire the other. Push it to a plain file outside the skill system: external reference any skill can point at.

## Splitting by invocation

The invocation cut of splitting (the sequence cut lives in `SKILL.md`): split off a model-invoked skill when you have a distinct leading word that should trigger it on its own (a trigger word you actually use in your prompts), or another skill must reach it. You pay context load for the new always-loaded description, so that independent reach has to be worth it.

## Router skills

When user-invoked skills multiply past what you can remember, that piled-up cognitive load is cured by a **router skill**: one user-invoked skill that names the others and when to reach for each, so the human has one skill to remember instead of many. It can only hint, never fire them: user-invoked skills have no description, so nothing but the human can reach them.

# Glossary

Terms used in code, tests and docs. Identifiers use these words, not synonyms. Entries marked
*(spike)* are already encoded in `spike/`; the rest enter the vocabulary when the core is built.
Physics claims behind them are checked in `docs/research/`.

## Oscillator

- **balance** — the oscillating wheel. Its angle from rest is `balanceAngle` (degrees). *(spike)*
- **hairspring** — the spiral spring returning the balance to rest. Its stiffness sets the period together with balance inertia.
- **amplitude** — peak balance angle from rest, degrees. Healthy at full wind: roughly 250–300° dial up. *(spike, as `balanceAmplitude`)*
- **beat** — one half-swing of the balance, from one extreme to the other. One tick. *(spike)*
- **beat rate** — beats per hour (bph). 18,000 bph = 5 beats/s = 0.4 s period. *(spike)*
- **period** — time for a full swing (two beats). *(spike)*
- **regulator index** — the lever that slides the curb pins along the hairspring, changing its active length and so the rate. Marked F/S or +/−.
- **timing screws** — screws on the balance rim; turning them in or out changes balance inertia and so the rate.
- **stud** — the fixed outer anchor of the hairspring. Rotating the stud carrier changes where the balance rests relative to the fork: the **beat adjustment**.
- **poise** — the balance's mass balance about its axis. A **poise error** (heavy spot) changes rate in vertical positions.
- **isochronism** — the property of keeping the same period at any amplitude. Its absence is **isochronism error**.

## Escapement

- **escape wheel** — the toothed wheel the gear train drives; released one half-tooth per beat. `wheelAngle` is degrees of rotation in the direction of tooth travel. *(spike)*
- **tooth pitch** — 360° / tooth count. 24° for 15 teeth. *(spike)*
- **pallet fork** (lever) — the pivoted piece carrying two pallet stones and the notch. Its angle from centre is `forkAngle`. *(spike)*
- **pallet stone** (pallet) — the jewel that stops and then pushes the escape wheel. **Entry** stone meets each tooth first; **exit** stone last. *(spike)*
- **locking face** — the stone face a tooth rests on while the wheel is stopped. *(spike)*
- **impulse face** — the inclined stone face a tooth slides along, pushing the fork. *(spike)*
- **locking corner** — where the two faces meet. **Let-off corner** — the far end of the impulse face, where the tooth leaves. *(spike)*
- **lock** — the phase with the tooth at rest on a locking face. `lockAngle` is the lever rotation needed to unlock. *(spike)*
- **unlock** — the lever lifting a stone until the tooth tip passes the locking corner. *(spike)*
- **impulse** — the tooth sliding along an impulse face and pushing the fork, which pushes the balance. `liftLever` is the lever rotation it spans. *(spike)*
- **drop** — the escape wheel in free flight between leaving one stone and landing on the other. `drop` is the wheel rotation it spans. *(spike)*
- **run to banking** — the lever's remaining travel after drop until it rests on a banking pin. *(spike)*
- **banking** — the pins that limit lever travel; the lever rests on one between beats. *(spike)*
- **draw** — an angle on the locking face so the wheel's torque pulls the lever onto its banking. Zero in the spike.
- **impulse pin** (roller jewel) — the pin on the balance that enters the fork's **notch** each beat. *(spike)*
- **lift angle** — the balance's travel while the impulse pin is in the notch. Timegraphers assume it (52° default) to compute amplitude. *(spike, as `liftAngle`)*
- **tangential geometry** — the layout rule placing the fork pivot where lines tangent to the escape wheel meet, with the stones at the tangent points. *(spike)*
- **circular / equidistant pallets** — two conventions for where the entry and exit lock arcs sit; the choice makes the two impulses asymmetric. The spike is circular.

## Instrument

- **timegrapher** — the bench instrument that listens to the ticks and reports rate, amplitude and beat error.
- **rate** — gain or loss in seconds per day (s/day). Positive = fast.
- **beat error** — the difference in milliseconds between tick-to-tock and tock-to-tick intervals. Zero means the balance rests centred.
- **trace** — the timegrapher's dotted plot of tick timing against beat number: slope is rate, separation of the two lines is beat error.

## Power

- **mainspring** — the coiled spring that stores energy. Its **torque curve** falls as it unwinds, lowering amplitude.
- **state of wind** — how much of the mainspring's run time remains.
- **gear train** — the wheels between mainspring and escape wheel; simplified in the drawing.

## Bench

- **calibre** — a named movement; one parameter set in the watch catalog.
- **position** — the watch's orientation (dial up, crown down, …) during timing.
- **puzzle** — a bundled faulty calibre with a symptom, a hidden cause and a completion rule.

import { distToSegment, len, sub } from "./geom2d";
import { stones, toothPolygons, stonePenetration } from "./shapes";

export type Phase = "lock" | "unlock" | "impulse" | "drop";
export type StoneName = "entry" | "exit";
export type Face = "locking" | "impulse";

export interface EscapementPose {
  balanceAngle: number;
  forkAngle: number;
  wheelAngle: number;
  phase: Phase;
  contact: { stone: StoneName; face: Face } | null;
  /** Count of steps where lever motion drove a stone into a tooth by more than NUDGE_TOL degrees. */
  violations: number;
  /** Largest nudge (degrees) ever needed to clear such a penetration. */
  maxNudge: number;
}

/** Contact solver tolerance: a resting tooth may be pressed this far (scene units) into a face. */
export const CONTACT_TOL = 1e-6;
/** Residual from finite steps along the lock arc. */
const NUDGE_TOL = 1e-3;
/** Largest internal step, seconds. Keeps the contact search well below a tooth width. */
const MAX_SUBSTEP = 1e-4;

/** Fork angle the impulse pin imposes at a given balance angle; the fork parks at a banking
 *  whenever the pin is out of the notch (zero draw: nothing else moves it). */
export function forkFor(p: EscapementParams, balanceAngle: number): number {
  const half = p.liftAngle / 2;
  const x = Math.max(-half, Math.min(half, balanceAngle));
  return (x / half) * derived(p).forkHalf;
}

/** A pose with the wheel settled against whichever stone the given balance angle locks. */
export function initialPose(p: EscapementParams, balanceAngle: number): EscapementPose {
  const fork = forkFor(p, balanceAngle);
  const wheel = advance(p, fork, 0, 2 * derived(p).pitch).wheel;
  return { balanceAngle, forkAngle: fork, wheelAngle: wheel, phase: "lock", contact: classify(p, fork, wheel), violations: 0, maxNudge: 0 };
}

/** Advance the escapement by dt seconds while the balance moves from prev.balanceAngle to balanceAngle. */
export function step(p: EscapementParams, prev: EscapementPose, balanceAngle: number, dt: number): EscapementPose {
  const n = Math.max(1, Math.ceil(dt / MAX_SUBSTEP));
  let pose = prev;
  for (let i = 1; i <= n; i++) {
    const bal = prev.balanceAngle + ((balanceAngle - prev.balanceAngle) * i) / n;
    pose = substep(p, pose, bal, dt / n);
  }
  return pose;
}

function substep(p: EscapementParams, prev: EscapementPose, bal: number, dt: number): EscapementPose {
  const fork = forkFor(p, bal);
  let wheel = prev.wheelAngle;
  let violations = prev.violations, maxNudge = prev.maxNudge;
  if (worst(p, fork, wheel) > CONTACT_TOL) {
    const nudged = clear(p, fork, wheel);
    const nudge = Math.abs(nudged - wheel);
    if (nudge > maxNudge) maxNudge = nudge;
    if (nudge > NUDGE_TOL) violations++;
    wheel = nudged;
  }
  const r = advance(p, fork, wheel, p.freeRunSpeed * dt);
  wheel = r.wheel;
  let phase: Phase;
  let contact: EscapementPose["contact"] = null;
  if (!r.blocked) phase = "drop";
  else {
    contact = classify(p, fork, wheel);
    if (contact.face === "impulse") phase = "impulse";
    else {
      const dFork = fork - prev.forkAngle;
      const lifting = (contact.stone === "entry" && dFork < -1e-12) || (contact.stone === "exit" && dFork > 1e-12);
      phase = lifting ? "unlock" : "lock";
    }
  }
  return { balanceAngle: bal, forkAngle: fork, wheelAngle: wheel, phase, contact, violations, maxNudge };
}

/** Largest penetration between any tooth and either stone. */
function worst(p: EscapementParams, forkAngle: number, wheelAngle: number) {
  const { entryStone, exitStone } = stones(p, forkAngle);
  let max = -Infinity;
  for (const tooth of toothPolygons(p, wheelAngle)) {
    for (const s of [entryStone, exitStone]) {
      const pen = stonePenetration(tooth, s);
      if (pen > max) max = pen;
    }
  }
  return max;
}

function classify(p: EscapementParams, forkAngle: number, wheelAngle: number): { stone: StoneName; face: Face } {
  const { entryStone, exitStone } = stones(p, forkAngle);
  let best = { d: Infinity, stone: "entry" as StoneName, face: "locking" as Face };
  for (const tooth of toothPolygons(p, wheelAngle)) {
    const tip = tooth[0];
    for (const [name, s] of [["entry", entryStone], ["exit", exitStone]] as const) {
      const dImp = distToSegment(tip, s.corner, s.letoff);
      const dLock = Math.abs(len(sub(tip, s.pivot)) - s.lockRadius);
      if (dImp < best.d) best = { d: dImp, stone: name, face: "impulse" };
      if (dLock < best.d) best = { d: dLock, stone: name, face: "locking" };
    }
  }
  return { stone: best.stone, face: best.face };
}

/** Nearest wheel angle (either direction, within half a degree) at which the pose no longer penetrates. */
function clear(p: EscapementParams, fork: number, wheel: number) {
  const search = (dir: 1 | -1) => {
    let lo = wheel, hi = wheel + dir * 0.5;
    if (worst(p, fork, hi) > CONTACT_TOL) return Infinity;
    for (let i = 0; i < 40; i++) {
      const mid = (lo + hi) / 2;
      if (worst(p, fork, mid) <= CONTACT_TOL) hi = mid; else lo = mid;
    }
    return hi;
  };
  const fwd = search(1), back = search(-1);
  if (fwd === Infinity && back === Infinity) return wheel + 0.5; // hopeless; let the violation show
  return Math.abs(fwd - wheel) <= Math.abs(back - wheel) ? fwd : back;
}

/** Move the wheel forward by up to `maxStep` degrees, stopping at first contact. */
function advance(p: EscapementParams, fork: number, wheel: number, maxStep: number) {
  const target = wheel + maxStep;
  if (worst(p, fork, target) <= CONTACT_TOL) return { wheel: target, blocked: false };
  let lo = wheel, hi = target;
  for (let i = 0; i < 40; i++) {
    const mid = (lo + hi) / 2;
    if (worst(p, fork, mid) <= CONTACT_TOL) lo = mid; else hi = mid;
  }
  return { wheel: lo, blocked: true };
}

/** Bessel function of the first kind, order 1, by power series (converges for all x; fine below ~30). */
export function besselJ1(x: number): number {
  const half = x / 2;
  let term = half; // k = 0: (x/2)^1 / (0! 1!)
  let sum = term;
  for (let k = 1; k < 60; k++) {
    term *= -(half * half) / (k * (k + 1));
    sum += term;
    if (Math.abs(term) < 1e-17 * Math.abs(sum)) break;
  }
  return sum;
}

 * Rate error from a balance poise error (heavy spot), per docs/research/04-positional-error.md,
 * verified against Rolex patent US10120341B2 claim 9 (citing Augsburger 1966):
 *
 *   rate_sd = 86400 · g · u · cos(φ) · sin(tilt) / (I · ω0²) · J1(Θ) / Θ
 *
 * Sign: heavy spot at the bottom (φ = 0) in a vertical position gains below the first zero of
 * J1 (Θ ≈ 219.5°) and loses above it.
 */
import { besselJ1 } from "./bessel";

export const G = 9.80665;

export interface PoiseInput {
  /** Unbalance, mass × eccentricity, kg·m (1 µg·cm = 1e-11 kg·m). */
  unbalance: number;
  /** Heavy-spot angle from the downward vertical when the balance is at rest, radians. */
  heavySpotAngle: number;
  /** Angle of the balance axis from vertical: 0 dial up or down, π/2 in any vertical position. */
  tilt: number;
  /** Balance moment of inertia, kg·m² (1 mg·cm² = 1e-10 kg·m²). */
  inertia: number;
  /** Natural angular frequency, rad/s (2π × balance frequency in Hz). */
  omega0: number;
  /** Amplitude, radians. */
  amplitude: number;
}

export function poiseRateSecondsPerDay(i: PoiseInput): number {
  if (i.amplitude <= 0) return 0;
  return (86400 * G * i.unbalance * Math.cos(i.heavySpotAngle) * Math.sin(i.tilt)) / (i.inertia * i.omega0 * i.omega0) * (besselJ1(i.amplitude) / i.amplitude);
}

export const POISE_CROSSOVER_DEG = 219.54;
